## 🟣 Technical Projects

### VioletOps — Enterprise-Style SOC & Purple-Team Homelab

[VioletOps](https://github.com/BexPy/VioletOps) is a hands-on cybersecurity lab project I built to move beyond studying security concepts and practice how they connect inside an operational environment.

I designed and documented a dual-host Microsoft Hyper-V lab with **OPNsense, Windows Server Active Directory, Windows 11, Kali Linux, Splunk Enterprise, Wazuh, Sysmon, Windows Firewall telemetry, and PowerShell**.

Through VioletOps, I practiced:

- **SOC alert triage and investigation** — reviewed 21 alerts and documented investigation cases, dispositions, escalation decisions, and shift handoffs.
- **Cross-source evidence correlation** — worked across Splunk, Wazuh, Sysmon, Windows event data, PowerShell logs, firewall telemetry, and endpoint context.
- **Detection engineering and validation** — created and tested detections mapped to MITRE ATT&CK techniques including **T1046 Network Service Discovery** and **T1018 Remote System Discovery**.
- **Purple-team methodology** — simulated controlled activity, observed telemetry, identified detection gaps, improved visibility and detections, and retested to validate the result.
- **Security automation** — developed a PowerShell SOAR-style workflow for alert normalization, enrichment, risk scoring, analyst approval, and audit logging.
- **Technical documentation** — maintained structured evidence, architecture documentation, investigation records, validation criteria, and sanitized public artifacts throughout the project.

## 🔎 How I Approach Technical Work

### Investigate with context

I practice treating an alert's severity as **one signal, not the entire conclusion**. Evidence, scope, affected assets, surrounding activity, and potential business impact all help determine what an alert actually means.

### Document as I go

Documentation comes naturally to me. I tend to build timelines, checklists, and structured notes while working through a problem so the evidence trail can be understood, reproduced, and continued by someone else.

### Work within scope

I don't assume every problem needs to be solved alone or all at once. I focus on understanding the scope, gathering enough evidence to make a defensible assessment, documenting what I've found, and recognizing when a problem requires additional knowledge, tools, authority, or another perspective.
